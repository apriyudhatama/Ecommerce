# IT Support Ticketing System

A simple web-based ticketing system built using PHP and MySQL to manage IT support requests.

## 🔍 Features
- User authentication (login/logout)
- Create support tickets
- View ticket list
- Simple dashboard monitoring

## 🛠 Tech Stack
- PHP (Native)
- MySQL
- HTML

## 🎯 Purpose
This project simulates a real-world IT support workflow where issues are logged, tracked, and resolved efficiently.

## 🚀 How to Run
1. Import `database.sql` into MySQL
2. Run project in localhost (XAMPP/Laragon)
3. Access via browser
